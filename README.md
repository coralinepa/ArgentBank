ArgentBank – Application bancaire en React + Redux

ArgentBank est une application de gestion de compte bancaire, développée avec React et Redux.
L’objectif est de construire une application full front-end, avec des appels API sécurisés, une authentification JWT, et une interface utilisateur propre et responsive.

Compétences mises en œuvre
- Implémenter la connexion utilisateur avec JWT
- Gérer l'état global avec Redux Toolkit
- Effectuer des requêtes API sécurisées (token Bearer)
- Structurer une application React professionnelle
- Créer des composants réutilisables
- Utiliser des middlewares et slices Redux

Fonctionnalités principales
- Formulaire de connexion sécurisé
- Routage conditionnel : accès restreint aux utilisateurs connectés
- Récupération et mise à jour des informations utilisateur
- Vue synthétique des comptes (solde, détails)
- Pages de compte et transactions (mock)
- Gestion des erreurs d’authentification

Technologies utilisées
- React 18
- Redux / Redux Toolkit
- React Router v6+
- Axios
- JWT (JSON Web Token)
- Sass / CSS Modules
- Git & GitHub

🚀 Installation
1. Cloner le dépôt
```git clone https://github.com/coralinepa/ArgentBank.git```
```cd ArgentBank```
2. Installer les dépendances
```npm install```
3. Lancer l’application
```npm start```
```Ouvre http://localhost:3000```
